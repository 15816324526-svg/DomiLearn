# 第一课单词与课文提取设计

## 目标

用户上传《现代西班牙语1》后，DomiLearn 在 PDF 转换完成时自动识别第一课的课文和词表，并按教材版本、课次、PDF 页码分类存储。现有教材目录只显示既有转换成功或失败状态，不新增预览、逐条编辑或二次确认界面。运行时不调用 LLM 或远程服务。

## 已观察到的教材结构

- 已转换的 305 页 Docling JSON 包含文本、页码及表格坐标。
- 第一课从 PDF 第 16 页开始，第二课从第 32 页开始；第一课的两篇课文在第 17～18 页，词表在第 18～19 页。
- Docling 将第 18 页词表每半页的多行合并成一行表格单元，无法仅按 JSON 表格行准确对齐单词和释义。
- 原 PDF 的词表每页有左右两组“词形、词性、释义”列。本机 RapidOCR 能按单行返回文字和坐标，因此可对词表所在页进行局部补充 OCR。

## 处理流程

1. 转换器生成 Markdown 和 Docling JSON，并通过现有页数校验。
2. 提取器读取 JSON，寻找正文内的“第一课”“第二课”、`TEXTOS` 与 `VOCABULARIO` 标志，确定范围。若标志缺失，返回明确的提取失败，不能把练习或目录当课文。
3. 在课文范围内读取 Docling 的文本块，按标题划分两篇课文；保存标题、内容、页码和原始 OCR 内容。
4. 依据 JSON 表格坐标，从原 PDF 渲染第 18～19 页。RapidOCR 在本机识别文字框；按左右两组的列坐标和纵向行位置，配对词形、词性、中文释义。只保存有西语词形且有释义的条目，保留原始 OCR 行以供将来追溯。允许少量拼写及配对误差。
5. 在数据库事务中，连同转换版本一起写入第一课、单词和课文。该版本尚未确认时，分类数据已保存，但只有已确认版本可供未来学习功能读取；沿用现有版本确认按钮，没有第二个确认步骤。
6. 对已经转换成功的现存版本提供一次性、可重复运行的补齐命令。重复执行不产生重复单词或课文；旧确认版本始终保留。

## 数据与界限

- 只实现教材 ID `modern-spanish-1` 的第一课，`lesson_number=1`。
- 每条单词保存词形、可为空的词性、中文释义、页码、在课内的顺序和原始 OCR 内容；课文保存标题、正文、页码和顺序。
- 分类结果按 `conversion_version_id` 隔离；新版本不能覆盖旧版分类。
- PDF 与 Docling JSON 不被改写。解析失败会使新任务失败并保存原因，现有已确认版本不受影响。
- 不生成学习计划，不连接背单词页面，不新增前端页面或 LLM 调用。

## 验收

- 真实教材至少识别两篇课文和足量的第 18～19 页单词，页码正确，不混入目录或练习。
- 重复补齐同一版本不会产生重复条目。
- 新上传的转换任务只有在分类数据落库后才进入“等待确认”；确认后可通过后端查询当前版本的第一课内容。
- 测试使用小型合成文档验证分组与数据库行为，并用现有真实教材运行一次本地验收。
