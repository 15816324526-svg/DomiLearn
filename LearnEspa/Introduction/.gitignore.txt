Introduction of .gitignore
==========================================================================
When submitting the project to Git for storage, 
a list of files that shound not be included.
==========================================================================
# 以 # 开头的是注释
node_modules/    # 实际使用时，说明通常单独写在上一行
dist/
*.log
!important.log
==========================================================================
# 一句话	注释，方便人阅读；Git 忽略这一行

文件夹名/	忽略这个文件夹及里面的文件；末尾 / 表示文件夹

*.log	* 是通配符，匹配所有以 .log 结尾的文件

!important.log	! 表示例外：即使符合前面的忽略规则，也保留这个文件

空行	只用于分隔，让清单更好读
===========================================================================
