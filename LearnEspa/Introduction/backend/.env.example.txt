Introduction Of .env.example
===================================================================================
It is typically one setting per line:
Setting Name = Setting Value
Such as:
APP_PORT=8000
DATABASE_URL=sqlite:///storage/app.db
The term "example" in the file name indicates "a fill-in" sample for developers.
The program is currently configued to read for .env.
====================================================================================
