Introduction Of dist
===========================================================================
运行 npm run build 后，Vite 会把前端代码加工成可部署的网页文件，放进 dist。
The output generated by vite using our 'src' code and required dependencies
===========================================================================

===========================================================================
dist/
├─ index.html          Webpage entry point
└─ assets/
   ├─ index-xxxx.js     JavaScript to be executed by the browser
   ├─ index-xxxx.css    Page Style
   └─ 页面名-xxxx.js     The code for these pages themselves
----------------------------------------------------------------------------
src/ 中方便人阅读和修改的代码
          ↓ npm run build
dist/ 中方便浏览器加载的网页文件
----------------------------------------------------------------------------
dist/
├─ index.html
└─ assets/
   ├─ index-BhuQBYyM.js
   ├─ index-CcwBKljs.css
   ├─ Dashboard-B5lNDO1Z.js
   ├─ Dashboard-BK-Y4ETy.css
   ├─ Directory-DAi4Jb5n.js
   ├─ Workspace-B1VU3w8s.js
   └─ Report-BNwawD4u.js
-----------------------------------------------------------------------------
它也可以从源代码重新生成，所以通常不保存进 Git。
It can be regenerated from source code, so it s usually not saved in Git.
以后部署网站时仍然会用到构建出的文件；“不交给 Git 保存”不等于“这个文件夹没用”。
The built file will still be used when deploying website in the future:
"not committing to Git "does not mean "the folder is useless"
