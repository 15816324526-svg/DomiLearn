## 项目介绍｜精简版

DomiLearn 是一款面向西班牙语初学者的本地 AI 辅助学习原型。它将《现代西班牙语 1》PDF 整理成章节、单词和课文，先通过释义选择与西语拼写帮助学习者记词，再依据教材句式、错词和历史练习记录生成新的课文情景。学习者逐句写出西语，获得针对意思、语法和教材句式的反馈；完成后可查看报告并再次练习同一篇课文。当前版本支持本机单用户和这一本教材，后续将继续打磨识别质量与仿写体验。

## 项目介绍｜详细版

DomiLearn 希望解决语言学习中“认识单词，却难以把教材表达用到新情景”的问题。作品以《现代西班牙语 1》为起点：用户上传教材 PDF，后端使用 Docling 与本地 OCR 转换和识别内容，再按章节保存词汇与课文。背词环节包括“看西语选中文释义”和“看中文拼写西语”，答错的词会在本轮重新出现，并成为后续仿写可参考的学习记录。

仿写是作品的核心。用户选定一篇教材课文后，系统参考原文句式、该课错词及过去的仿写记录，调用 DeepSeek 生成保留原文对话或叙述结构的新中文情景。用户每次只写一句西语；模型对意思、语法和句式使用给出解释及修改建议。全部句子完成后，系统保存每次尝试、生成学习报告，并允许再次练习同一篇课文。当前版本在 Windows 本机运行，支持单用户及《现代西班牙语 1》；多教材与多用户部署仍属于后续版本。

## AI 使用声明｜精简版

本作品由参赛者提出产品目标、学习流程与关键功能决策，并在开发中使用 OpenAI Codex 辅助方案讨论、部分代码编写、测试和文档整理；参赛者持续审查实现与实际效果。产品运行时，Docling 和本地 OCR 负责 PDF 解析，不调用外部大模型；DeepSeek 官方 API 用于仿写情景生成、逐句反馈、记忆摘要与学习报告。当前模型任务由项目代码编排，尚未使用 LangChain/LangGraph。AI 生成的内容可能出错，教材识别与教学反馈仍需人工核查。

## AI 使用声明｜详细版

**开发过程：**参赛者负责提出问题、确定产品范围与交互规则，并对功能进行试用、反馈和代码审查。OpenAI Codex 被用于辅助技术讨论、生成和修改部分前后端代码、编写测试及整理文档。因此，本作品不将全部代码表述为参赛者手工逐行编写，也不将 AI 产出视为免审查的结果。

**产品运行：**教材导入使用开源工具 Docling 与本地 RapidOCR，章节和词汇分类主要使用针对当前教材版式的程序规则；背词判分不调用外部大模型。仿写环节调用用户配置的 DeepSeek 官方 API，用于整理可参考的学习记录、规划和生成新情景、审核题目、逐句给出反馈以及撰写学习报告。相关教材句子与练习记录会随仿写请求发送到模型服务，调用可能产生 Token 费用。当前实现通过项目代码按固定流程调用模型，未接入 LangChain/LangGraph，也没有通用的自主工具调用 Agent。我们将持续核查 OCR 识别和模型教学反馈的准确性。
